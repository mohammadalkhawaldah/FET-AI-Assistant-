# FET AI Assistant

مساعد عربي صوتي يعتمد على بياناتك، مع أفاتار متحدث من **Simli** ومحادثة مباشرة عبر **Google Gemini Live**. يعمل محليًا على Windows داخل Chrome، ويتيح مقاطعة المساعد بالكلام أثناء رده.

## النسخة الحالية

- المحادثة: `gemini-3.8-live`.
- الصوت: `Zephyr`، مع تعليمات للهجة الأردنية في `instructions.txt`.
- الأفاتار: Face ID مضبوط مسبقًا في `run_assistant_avatar.py`، ويمكن تغييره عبر الثابت `FACE_ID`.
- معالجة الميكروفون: إلغاء الصدى وتقليل الضجيج عبر المتصفح، مع استمرار إرسال الصوت أثناء الرد.
- المقاطعة: إيقاف صوت الأفاتار محليًا وإفراغ صوت Simli المنتظر عند استقبال إشارة المقاطعة من Google.
- مدة التجربة: 180 ثانية، ويمكن بدء جلسة جديدة بعدها.
- توجد نسخة صوتية مستقلة احتياطية في `run_assistant_browser.py`.

## المتطلبات

- Python 3.10 أو أحدث.
- Chrome، وميكروفون وسماعات الكمبيوتر، واتصال بالإنترنت.
- مفتاح Gemini API ومفتاح Simli API من حسابيك.

لا يتطلب التشغيل Node.js؛ مكتبة Simli للمتصفح مضمّنة في ملف Python.

## التشغيل على Windows / PowerShell

افتح PowerShell داخل مجلد المشروع. عند الإعداد للمرة الأولى:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

ثم شغّل نسخة الأفاتار:

```powershell
.\.venv\Scripts\python.exe run_assistant_avatar.py
```

افتح في Chrome:

```text
http://127.0.0.1:8765
```

أدخل مفتاح Google ومفتاح Simli في خانتيهما، واضغط **بدء المحادثة**، واسمح بالميكروفون. انتظر اتصال الأفاتار ثم تحدث. للمقاطعة، تحدث أثناء رده؛ لا يوجد زر مطلوب للمقاطعة.

أبقِ الطرفية مفتوحة أثناء الاستخدام. لإنهاء التطبيق اضغط `Ctrl+C` في الطرفية.

للتشغيل لاحقًا، يكفي أمر تشغيل البرنامج. إذا كانت لديك بيئة المشروع السابقة مثبتة فلا تحتاج إلى إنشائها مجددًا.

### النسخة الصوتية الاحتياطية

```powershell
.\.venv\Scripts\python.exe run_assistant_browser.py
```

تحتاج هذه النسخة إلى مفتاح Google فقط. أوقف النسخة الأخرى أولًا لأنهما تستخدمان المنفذ نفسه.

## تخصيص البيانات واللهجة

عدّل `instructions.txt` واحفظه بترميز UTF-8، ثم ابدأ جلسة جديدة. يحتوي الملف الحالي على بيانات تجريبية عامة عن الخدمات وقواعد الإجابة واللهجة.

هذه النسخة تُدخل النص مباشرة في تعليمات النموذج؛ لا تتضمن بعدُ فهرسة مستندات أو RAG أو ربط CRM أو تسجيل حجوزات. لا تضف معلومات لا تسمح بإرسالها إلى خدمات المعالجة المستخدمة.

## المفاتيح والتكاليف

- يطلب التطبيق المفتاحين عند بدء الجلسة ولا يحفظهما في الملفات أو تخزين المتصفح.
- إنشاء رمز جلسة Simli يجري في خادم Python المحلي؛ مكتبة Simli في المتصفح تتلقى رمز الجلسة المؤقت فقط.
- الخادم يستمع على `127.0.0.1`، وليس واجهة نشر عامة أو سحابية.
- خدمات Google وSimli تخضع لحصص وأسعار حسابيك. التشغيل المحلي لا يجعل خدمات API غير محدودة أو مجانية تلقائيًا.
- يستخدم التطبيق الحصص المتاحة؛ لا يفعّل الفوترة أو يغيّر الاشتراك. تحديد مدة الجلسة ليس سقفًا ماليًا.
- لا تضع المفاتيح في الكود أو المستودع. ملفات `.env` والبيئة الافتراضية مستبعدة بواسطة `.gitignore`.

## ملفات المشروع

| الملف | الغرض |
|---|---|
| `run_assistant_avatar.py` | نسخة Gemini + Simli، مع مكتبة المتصفح المضمّنة |
| `run_assistant_browser.py` | النسخة الصوتية المستقلة |
| `instructions.txt` | بيانات الخدمات وتعليمات المحادثة |
| `requirements.txt` | مكتبات Python وإصداراتها المثبتة |
| `THIRD_PARTY_NOTICES.txt` | تراخيص مكتبة Simli واعتماديات المتصفح المضمّنة |

## التحقق

أبلغ المستخدم عن نجاح النسخة الصوتية ثم نسخة الأفاتار على جهازه. اختُبرت أيضًا إعدادات SDK، وتحويل PCM من 24 إلى 16 kHz، وتسلسل تشغيل الأفاتار، واستمرار الميكروفون، وإفراغ الصوت عند المقاطعة، وإغلاق الجلسات باستخدام محاكاة الخدمات. لا تتطلب هذه الاختبارات نشر مفاتيح حقيقية.

تتأثر جودة المقاطعة وإلغاء الصدى بأجهزة الصوت والمتصفح والشبكة.
